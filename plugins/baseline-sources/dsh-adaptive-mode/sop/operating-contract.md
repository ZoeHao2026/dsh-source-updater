# 跨任务 SOP：执行边界

适用：Router 判定为非简单任务时按需读取。这里仅保存所有任务类型共享的约束；任务策略见对应 Playbook，步骤调度见 `workflow/dynamic.md`。

## 授权与兼容

以用户当前目标和已有授权确定可执行范围。识别会受影响的接口、配置、数据和用户习惯；保留仍有效的能力。改变重要状态前确认影响范围与恢复手段，恢复材料应覆盖相关依赖，而不只是目标文件。

## 外部效果

对可能重复生效的安装、提交、发布或远端写入，结果不明时先读取真实状态再决定是否重试。不要把工具返回成功视作外部效果已经完成，也不要因响应超时直接重放操作。

## 证据与声明

先确定与目标相称的成功证据。交付时区分已验证、未验证与失败；重要结论须能由实际产物、运行状态或可回读来源支持。验证不通过时记录失败事实并交给动态工作流处理。

## 最小状态

只在当前任务的 todo／会话上下文保留目标、关键决定、当前进度、恢复点和未决证据。过期假设及时移除；未经用户要求，不写入跨任务持久记忆。
