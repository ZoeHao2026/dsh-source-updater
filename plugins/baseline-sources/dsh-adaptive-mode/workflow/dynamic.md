# Dynamic Workflow：复杂任务调度

输入是 Router 的任务判断、相关 Playbook、跨任务 SOP 与已观察到的状态。本文件只用于已进入原生计划模式的复杂任务或高风险状态变更；简单任务的直接执行由 Router 决定。

## 规划与执行

在原生计划模式中先做只读探索，澄清成功条件、依赖、风险与可验证的阶段；通过原生 `exit_plan_mode` 提交计划并等待其批准。批准后使用现有 todo 记录必要进度。每次仅选择当前证据支持、依赖已满足且可以核查结果的下一步，不把初始计划当作不可调整的脚本。

## 并行与调整

只有独立任务存在明确并行收益时才使用子代理或标准模式已有 workflow 工具；明确子任务输入、边界和交付证据，主 Agent 核查并整合结果。新事实改变前提、风险或依赖时，保留仍有效的工作并修改受影响的后续步骤；计划不再适用时重新规划。

## 评估反馈

在有实际影响的阶段及结束前，使用 SOP 的证据要求和 Playbook 的专项验收信号检查结果。失败时先定位原因：可局部修正则有限重试，外部效果不明则先对账，目标或前提变化则重新规划。向用户报告已证实结果与未完成范围。
