# 视觉与动效语言

目标：每个镜头都在运动，每次运动都有动机，任何时刻都不出现"PPT 感"。

## 1. 允许并优先使用的技法
- **镜头运动**：推入/拉出、横移、绕行、手持微抖、机位随内容位移；运动用缓入缓出，短促动作可用 Spring 回弹。
- **缓动与 Spring**：入场用 `easeOut` 类或 Spring（刚度高、阻尼足，避免长时间摇晃）；驻留用极缓的连续漂移；出场用 `easeIn` 类并快速收敛。
- **运动模糊**：速度快的元素（文字扫入、粒子、甩镜）加方向性模糊；静态元素不加。
- **视差与景深**：前景/中景/背景三层以上，位移量与镜头距离成比例；3D 场景给不同层不同焦点与模糊半径。
- **辉光/Bloom**：只作用于自发光元素（数字、光点、描边），阈值与半径写进规范，避免整屏泛白。
- **粒子与流场**：用于氛围与能量传递，数量与生命周期有上限，粒子自身要有运动而非静态贴图平移。
- **着色器/GLSL**：渐变噪声、位移扭曲、光照、液体/玻璃质感；着色器时间必须由帧号驱动。
- **动态字体/排版**：字重与字距随节奏变化、逐字/逐词入场、基线对齐动画、可读性始终优先。
- **遮罩与形变（Mask/Morph）**：形状过渡、路径变形、裁切揭示；变形两端都要是同一视觉语义的图形。
- **2.5D/3D**：平面分层 + 透视机位、卡片浮入空间、真实摄像机轨迹；不做无意义的绕轴旋转。
- **无缝转场**：匹配剪辑（图形/线条/运动方向接续）、遮罩推进、同物体形变、速度带、光照过曝收束。转场必须由前一个镜头的运动趋势引出。

## 2. 禁止清单
- PPT 式逐条出现：整屏文字一条条淡入、项目符号列表、静态页面停留。
- 把简单淡入淡出当默认转场；整片只靠 `opacity` 变化推动。
- 无动机的特效堆砌：同一镜头叠三种以上后处理、随机闪烁/抖动、与内容无关的粒子雨。
- 超过 1.5 秒的静止或近似静止画面（含"只有字幕在变而画面不动"）。
- 滥用外发光/彩虹渐变/阴影，造成廉价观感；对比度低于可读阈值的文字。
- 转场处出现黑场、白闪、画面跳到不连续位置；音频与画面在同一帧上互相错位。

## 3. 静止画面的处理
需要"停顿感"时，用这些方式保持画面持续运动：缓慢镜头漂移（每帧 0.2–1px 级）、轻微视差、粒子生命与呼吸、着色器低幅流动、文字字距/字重微变、景深焦点缓慢迁移。停顿是节奏，不是停帧。

## 4. 效果预算（写进 `visual-spec.json`）
| 项 | 上限 | 说明 |
| --- | --- | --- |
| 每镜头后处理层数 | 3 | 超过则合并或删除，优先保留景深与 Bloom |
| 每镜头同期动画元素 | 12 | 超出会显得嘈杂；主体 + 支撑 + 氛围三层即可 |
| 粒子数 | 视预算 | 以单帧耗时不超过 `tech-plan.md` 目标为上限 |
| 模糊半径与迭代 | 记入规范 | 大半径模糊必须抽帧确认没有闪烁 |
| 转场时长 | 0.3–0.8s | 超过 0.8s 需有明确理由（例如刻意延时揭示） |
| 同屏文字 | ≤ 2 组 | 一组为主信息，一组为支撑；数字可单独成组 |
| 调色板 | 3 主色 + 2 中性 | 强调色只用于强调 |

## 5. 排版与安全区
- 安全区：上下左右各留 5% 边距，字幕底部留 8%；任何文字不越界。
- 分辨率与字号：1080p 下正文最小 28px，字幕最小 34px；关键数字可放大到 80px 以上。
- 每屏文字量：中文不超过 14 字/行、3 行；英文不超过 40 字符/行、3 行。
- 字幕与画面文字不同时出现在同一区域，避免互相遮挡。
- 对比度：文字与背景亮度差不足时加半透明底衬或描边，不靠加大字号解决。

## 6. 节奏与镜头长度
- 前三秒必须有钩子：最强视觉或最反直觉的一句话。
- 常规镜头 2–6 秒；关键数字或情绪高点可停留到 8 秒（期间保持内部运动）；超过 8 秒必须拆分或加入视角变化。
- 转场密度：每 4–8 秒至少一次视觉结构变化（视角、构图、色彩或运动方向变化）。
- 音画卡点：重音落在转场或元素命中的那一帧，允许提前 1–2 帧。

## 7. 自检问句
每个镜头完成后问自己：这个镜头在"讲什么"？运动是否服务于它？把画面静音播放是否仍然可看？把画面遮挡只看运动是否仍然流畅？任一答案为否就修。
