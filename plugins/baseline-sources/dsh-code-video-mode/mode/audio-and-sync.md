# 音频、字幕与同步

## 1. 声床构成
| 层 | 作用 | 目标电平 | 备注 |
| --- | --- | --- | --- |
| 配音（VO） | 主信息 | 混音后约 -16 LUFS（整体 -14 LUFS 附近） | 每句独立文件，保留起止时间 |
| 字幕 | 同 VO 的可见形式 | 不参与混音 | 逐句对应，不改写 |
| BGM | 情绪与节奏 | 低于 VO 约 18–24dB | 开头 0.5–1s 淡入、结尾 1–2s 淡出 |
| SFX（Whoosh/Impact/Riser/Click/Tick） | 卡点与转场 | 峰值不高于 VO 峰值，短促 | 位置由镜头卡点决定，不凭感觉摆放 |

原则：任何时刻以"听得清人声"为第一约束；BGM 在 VO 出现处自动让位（侧链或手动降增益）。

## 2. 配音生成（本机 TTS 优先）
1. 口播稿按语义切句，每句一个 id（`vo-01`…），写进 `script.md` 与 `spec/audio-map.csv`。
2. 用本机 `edge-tts` 生成（中文语音优先 `zh-CN` 系列，具体音色名写入 `brief.md`）；无网络时优先使用用户素材，其次输出无声 + 完整字幕版本。
3. 语速按内容调节并在工程中固定（例：`--rate=+8%`）；生成后逐句试听，确认无吞字、无异常停顿。
4. 音频统一格式（例如 48kHz、单声道或立体声、WAV 中间态），避免采样率不一致导致时长漂移。

## 3. 字幕
- 与 VO 逐句一致；长句按呼吸点再切分，保证单行不超过 `mode/visual-language.md` 的字数上限。
- 每条字幕的起止由该句音频的实际起止推导，前后各留 80–150ms 余量，避免切在音节上。
- 字幕文件与实现同源：字幕数据由 `audio-map.csv` 生成，避免手写时间码与音频不同步。
- 检查项：无重叠、无跳字、无半行截断；换行处不在词中间（英文）或语义单位中间（中文）。

## 4. SFX 卡点设计
- 先列出"动作命中点"：转场、元素落位、数字变化、镜头切换、段落开始。
- 映射规则：转场 → Whoosh；重音/落位 → Impact；进入高潮前 0.5–1.5s → Riser；计数与小交互 → Click/Tick。
- 每个卡点写进 `storyboard.yml` 的 `audio_cue`，与 `timeline.csv` 的帧号对齐；同一卡点只用一个音效，避免叠加变脏。

## 5. 同步量测（强制）
1. 用 `ffprobe` 读每条 VO 的真实时长与采样率，不用估算值。
2. 把每句时长累加，校验是否与 `timeline.csv` 的视听节拍自洽；差异超过 2 帧（约 66ms）就修正时间线。
3. 导出后抽取每个转场帧与其前后各一帧，核对音效峰值是否落在该帧附近；偏差超过 2 帧就调整音效起点。
4. 整体校验：成片时长 = 视频流时长 = 音频流时长（允许 <1 帧差）；`ffprobe` 必须同时报告视频流与音频流。
5. 响度校验：用滤镜量测整体响度与峰值（例如 `loudnorm` 的测量输出），确认无削波、无人声被压。

## 6. 常见失效模式
- **音频比画面长/短**：时间线按音频实际长度重算，而不是拉伸音频。
- **字幕整体提前/延后**：多半是句界与音频不对应，重新按句切分而非全局平移。
- **BGM 盖住人声**：降低 BGM 增益或加侧链压缩，不要提高 VO 增益到削波。
- **音效听起来"晚一点"**：动画的落位帧由缓动尾部决定，应与 SFX 起点对齐到同一帧，而不是对齐到动画开始帧。
- **末尾被截断**：导出时长按帧数取整，末尾留 0.2–0.5s 收束（BGM 淡出或画面停留）。
- **重复渲染后音画漂移**：帧率不一致或音频被重采样两次；统一到同一采样率与帧率再混流。
