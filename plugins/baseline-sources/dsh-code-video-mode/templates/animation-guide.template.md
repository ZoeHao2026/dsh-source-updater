# 冻结后所有场景实现必须引用本文件的曲线与关键值，禁止在场景里临时改曲线。

| 名称 | 值 | 用途 |
| --- | --- | --- |

## 2. 相机运动规范
- 推入/拉出：全程幅度 3–8%，匀速为主，首尾各留 20% 时长做缓入缓出。
- 横移/绕行：路径为直线或大半径弧线，禁止折线；与前景元素位移量成比例。
- 手持微抖：幅度 ≤ 0.3% 尺寸、频率 0.5–2Hz；只在指定镜头启用。
- 每次镜头运动都要写明"服务于哪个节拍"，无动机的运镜删除。

## 3. 元素编排原则
- 一个镜头只设一个视觉主体；支撑元素不得抢注意力（对比度与运动幅度都更低）。
- 入场顺序：主体 → 支撑 → 氛围；同一时刻最多两处元素在动。
- 强调手段优先级：位置变化 > 尺度变化 > 颜色/发光 > 闪烁（闪烁默认禁用）。
- 数字与关键信息：出现后至少停留 1.2s 或到句子说完，不提前消失。

## 4. 转场实现约定
- 每个转场必须声明类型与承接逻辑（前一镜头的哪个元素/方向延续到后一镜头）。
- 匹配剪辑：共用图形或运动方向在同一帧交接，交接帧两边视觉中心位置一致。
- 遮罩推进：遮罩边缘运动方向与镜头运动方向一致，速度一致。
- 形变：两端图形语义相同（例如圆形数据点 → 圆形图标），中间不做无意义旋转。

## 5. 效果使用约束
- 后处理（景深/Bloom/运动模糊）总层数 ≤ 3；强度写在 `visual-spec.json` 并逐帧抽验是否闪烁。
- 粒子与着色器参数固定种子；同一镜头的粒子在重跑时位置一致。
- 运动模糊只在快速运动元素上使用；静态元素严禁加模糊。
