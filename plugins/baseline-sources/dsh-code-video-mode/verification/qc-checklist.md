# 成片验收清单（QC Gate）

用法：阶段 7 逐项执行，每项写"结论 + 证据"到 `out/qc-report.md`。证据必须是可复查的：命令输出摘要、抽帧文件名、目视判断的具体位置（时间码）。任一项失败即修正后复验；无法修正的按 `mode/operating-contract.md` 第 6 节止损并如实记录。

## A. 文件与流规格
- [ ] 成片文件存在，大小合理（非 0，与时长/码率相称）。
- [ ] `ffprobe` 报告视频流：编码 H.264、`yuv420p`、目标分辨率与帧率一致。
- [ ] `ffprobe` 报告音频流：AAC、采样率与声道符合规范。
- [ ] 视频时长与方案总时长一致（差值 < 1 帧）；音频流时长与之相符。
- [ ] 首帧与末帧不是黑帧/空帧（除刻意设计的黑场）。
- [ ] 总帧数与 `timeline.csv` 累计帧数一致。

## B. 动画流畅度
- [ ] 每个运动镜头在起始、中段、结束各抽 1 帧，共 3 帧，确认运动轨迹连续、无跳变。
- [ ] 无卡顿帧：单帧耗时日志中无异常尖峰（对比均值的 3 倍以上且出现在成片中）。
- [ ] 无冻结帧：任意连续 1.5 秒窗口内画面都有可辨运动（含镜头漂移、粒子、着色器流动）。
- [ ] 缓动自然：入场不"啪"地出现，出场不突然消失；Spring 无长时间余振。
- [ ] 文字动画无闪烁、无重影，字形无回退（中文与英文字重符合规范）。

## C. 转场与连续性
- [ ] 每个转场抽前后各 1 帧，共 2 帧：无黑场、无白闪、无位置/尺度跳变。
- [ ] 转场由前镜头运动趋势引出（匹配剪辑或遮罩推进），不是单纯叠化。
- [ ] 场景边界处音频不断裂（无爆音、无静音空隙）。
- [ ] 相邻镜头方向/结构有变化，未出现连续三个镜头构图雷同。

## D. 节奏与叙事
- [ ] 前三秒有钩子（最强画面或最反直觉的一句话）。
- [ ] 无超过 1.5 秒的静止画面，无超过 8 秒的未拆分镜头。
- [ ] 每 4–8 秒有一次视觉结构变化。
- [ ] 信息顺序可理解：不看字幕也能跟上主干。
- [ ] 结尾有收束（回到主信息或明确号召），不戛然而止。

## E. 音频与同步
- [ ] 响度在目标范围，峰值无削波（量测输出已记录）。
- [ ] 人声清晰：BGM 未盖住 VO。
- [ ] 每个卡点音效落在对应帧附近（偏差 ≤ 2 帧，已抽帧核对）。
- [ ] 无异常静音段、无爆音、无重复叠加的音效。
- [ ] BGM 淡入淡出完整，末尾未被截断。

## F. 字幕
- [ ] 字幕与配音逐句一致（内容、顺序、语气均对应）。
- [ ] 字幕起止与音频对齐（前后余量 80–150ms），无重叠、无跳字。
- [ ] 字幕在安全区内，字号与行数符合规范，对比度可读。
- [ ] 字幕与画面文字不重叠遮挡。

## G. 视觉规范符合度
- [ ] 调色板、字体、栅格与 `visual-spec.json` 一致。
- [ ] 效果在预算内（后处理层数、粒子数、转场时长）。
- [ ] 文字安全区、最小字号符合规范。
- [ ] 无违反禁止清单的镜头（PPT 式列举、纯淡入淡出、无动机特效）。

## H. 渲染完整性
- [ ] 帧序列无缺帧、无重复帧（文件数 = 预期帧数）。
- [ ] 无占位画面、无渲染报错帧、无未加载的图片/字体。
- [ ] 复现命令可用：README 中的一条命令可重新产出同一成片（同参数同种子）。
- [ ] 降级项（分辨率、音频能力、缺失的音效等）已在交付说明中列明。

## 结论模板
```
结论：通过 / 有条件通过 / 未通过
通过项：A1–A6, B1–B5, …
失败项与处置：<项号> <原因> <修正或止损说明>
未验证范围：<具体说明>
证据位置：out/qc-report.md, frames/*.png
```
