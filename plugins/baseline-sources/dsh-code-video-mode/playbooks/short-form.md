# Playbook：短内容（15–60 秒）

适用：`做一个 30 秒介绍 X 的视频`、社交短视频、产品一段式预告。目标是一口气看完、记住一句话。

## 结构模板（30 秒示例，按比例缩放）
| 段落 | 时长 | 作用 | 视觉 |
| --- | --- | --- | --- |
| 钩子 | 0–3s | 抛出问题或最强结果 | 最高对比画面 + 一次 Impact |
| 立题 | 3–8s | 说清是什么/给谁 | 关键词排版 + 镜头轻推 |
| 主体 | 8–22s | 2–3 个支撑点，每点一个镜头 | 图形/数据/流程动效，转场卡点 |
| 收束 | 22–27s | 回到主信息 | 匹配剪辑回到开场构图 |
| 落款 | 27–30s | 名称/号召 | 静态文字 + 持续漂移，非黑场 |

## 节奏约束
- 最长镜头 6s，最短 2s；每 4–6s 一次视觉结构变化。
- 口播总字数 ≈ 时长(秒) × 4.5 字（中文），宁少不多；字幕与口播一致。
- SFX：开场 Impact、每段转场 Whoosh、进入收束前 1s Riser、落款 Click。
- 效果预算：整片后处理平均 ≤ 2 层/镜头；粒子只在 1–2 个镜头出现，避免全程噪声。

## 文案要点
- 第一句不介绍背景，直接给结论或反常识点。
- 每句只承载一个信息；数字优于形容词，具体优于笼统。
- 屏幕文字是关键词，不是口播原文的复制；同一时刻最多两组文字。

## 验收侧重
- 3 秒内是否抓住注意力（不看字幕也能懂）。
- 是否只记住一件事；若记住三件事，说明信息过载，删到一件。
- 结尾是否回到主信息，而不是突然结束。
