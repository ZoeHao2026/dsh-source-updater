# Playbook：数据叙事（30–120 秒）

适用：把一个数字、一组趋势或一次对比讲清楚。目标是"看完相信这个数字"。

## 数据纪律
- 只用可溯源数据；来源写进 `brief.md`。没有真实数据就明确标注"示意数据"，绝不编造精确数值。
- 单位、量级、时间范围必须出现在画面里，不能只出现在口播里。
- 不做误导性视觉：坐标轴不为美观截断（若非零基线，必须显式标注），面积编码必须按面积比例。

## 结构模板
1. **数字本身（0–15%）**：先给结论数字，一个大字 + 一次 Impact 落位。
2. **量级校准（15–35%）**：把数字换成可感知的对比（相当于多少、多久、几个人）。
3. **变化过程（35–70%）**：时间序列或前后对比；用生长/推移动画，禁止把折线图直接"画出来就完"。
4. **拆解（70–90%）**：说明这个数字由什么构成；用分解动画展示构成关系。
5. **含义（90–100%）**：这对观众意味着什么；回到开场构图。

## 视觉策略
- 数值变化用锚定元素（数据点/柱体）的运动表达，不用纯文字跳动。
- 趋势线：线条生长带方向性运动模糊，关键拐点加停顿 + 标注。
- 对比：两组同构图形并列或分屏，差异用动效强调，不用颜色单独承担（色盲可辨）。
- 数字滚动必须与口播节拍同步；最终值落位帧与音频重音同一帧。

## 节奏约束
- 单次数据动画不超过 6s；超过则拆成"出现 → 生长 → 定格标注"三段。
- 每个数字至少停留 1.2s 或到句子读完。
- 每段结尾给一次"所以……"的解释镜头，避免只呈现不解释。

## 验收侧重
- 抽帧后单看画面能否读出数字、单位与时间范围。
- 无夸大表述；结论有数据支撑。
- 图表在安全区内，标注不被字幕遮挡。
