# Playbook：产品与品牌（30–90 秒）

适用：介绍一个产品、服务或品牌气质。目标是"看完知道它解决什么问题、为什么值得信赖"。

## 结构模板
1. **痛点（0–15%）**：观众此刻的麻烦，具体到一个瞬间（不是抽象口号）。
2. **转折（15–25%）**：产品出现的瞬间；一次最强视觉与最强的音效卡点。
3. **能力（25–65%）**：2–3 个核心能力，每个一个镜头，用"动作 → 结果"表达，不讲功能清单。
4. **可信（65–80%）**：数据、场景或过程证明；真实可核验的内容优先。
5. **品牌落款（80–100%）**：名称、标识、一句价值主张；画面保持持续运动。

## 视觉策略
- 品牌色作为唯一强调色，使用面积不超过画面的 20%；避免整屏色块。
- 产品形象用几何化/抽象化重构（代码生成），不直接使用未授权素材；有官方素材时须确认使用授权。
- 界面类内容用"动作演示"：指针移动 → 元素响应 → 结果出现，三步一镜，禁止静态截图停留。
- 落款镜头用缓慢推入或光流动，避免静止 logo 三秒。

## 节奏约束
- 每 5–8s 一次视觉结构变化；能力段落之间用匹配剪辑（同一元素延续）。
- 禁止列出功能清单式画面（三项并排逐条淡入属于 PPT 式，需改为依次演化或空间排列运动）。
- 结尾 1s 内收束，BGM 与画面同时淡出，不留空白尾帧。

## 文案要点
- 讲"用户获得什么"，不讲"我们用了什么技术"。
- 一句价值主张 ≤ 12 字，全片只出现一次作为主信息。
- 避免绝对化与无法验证的宣称（最好、第一、唯一）。

## 验收侧重
- 痛点与产品出现在前 8 秒。
- 品牌价值主张只出现一次且在最醒目的位置。
- 无未授权素材、无夸大宣称。
