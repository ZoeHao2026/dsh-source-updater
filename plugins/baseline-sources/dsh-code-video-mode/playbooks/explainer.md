# Playbook：解说与知识（60–180 秒）

适用：解释一个概念、原理、机制或流程。目标是让外行看懂主干，让内行不觉浅薄。

## 结构模板
1. **问题（0–10%）**：观众此刻真实的困惑，用一句话问出来。
2. **直觉（10–25%）**：用一个日常类比建立初始模型；画面用简化图形，不用专业术语。
3. **机制（25–65%）**：拆成 2–4 个递进环节，每环节一个场景；每环节结尾给一次"所以……"的小结镜头。
4. **反例/边界（65–80%）**：说明类比在哪里失效，避免误导；此处适合用对比画面。
5. **总结（80–95%）**：回到开场问题，用同一构图给出答案（匹配剪辑）。
6. **延伸（95–100%）**：可选，一句引导。

## 节奏约束
- 每 8–12s 一个小结或转折，避免长时间同质推进。
- 术语首次出现必须配一次视觉定义（图形 + 关键词），第二次才可直接使用。
- 类比与机制之间要有明确的视觉切换（同元素形变或视角切换），避免观众以为还是类比。
- 单场景镜头数 ≤ 4，避免场景内节奏断裂。

## 画面策略
- 结构类内容用"同构图形递进"：同一个基础形状在不同环节生长/拆分/重组，保持认知连续性。
- 数据必须真实可溯源；无真实数据时用"示意"明确标注（例如 `示意数据`），不得伪造精确数字。
- 复杂机制用分层：底层不变 + 高亮当前层，比整屏重画更易理解。

## 验收侧重
- 不做字幕也能跟上主干（信息在画面里）。
- 无一句话里出现两个以上专业术语。
- 结尾回答的正是开场提出的问题。
